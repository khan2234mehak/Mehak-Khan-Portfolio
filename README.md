## ⚙️ Getting Started

Want to run this portfolio locally? Follow these steps:

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/khan2234mehak/Mehak-Khan-Portfolio.git
```

### 2️⃣ Navigate to the Project

```bash
cd Mehak-Khan-Portfolio
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Development Server

```bash
npm run dev
```

⚡ The application will start on the local development server provided by Vite.

---

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
