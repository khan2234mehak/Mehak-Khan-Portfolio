## Getting Started

### Clone the repository

```bash
git clone https://github.com/khan2234mehak/Mehak-Khan-Portfolio.git
```

### Navigate to the project

```bash
cd Mehak-Khan-Portfolio
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

The application will start on the local development server provided by Vite.

## Production Build

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
